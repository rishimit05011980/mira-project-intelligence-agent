# Mira Project Overview

## 1. Problem Statement

Project management information is distributed across
different activities, updates and workstreams.

Mira explores how multi-agent AI architecture can
provide conversational access to specialised
project intelligence.

## 2. Solution Overview

Mira is a multi-agent prototype implemented using n8n.

A central conversational router processes incoming
requests and directs them to specialised workflows.

## 3. Agent Capabilities

| Agent | Responsibility |
|---|---|
| Plan | Project planning intelligence |
| Risk | Risk-related intelligence |
| Status | Project status insights |
| Milestone | Milestone tracking |
| Stakeholder | Stakeholder intelligence |

## 4. Architecture

The solution uses:

- Central Mira Router
- AI Agent for conversational processing
- Switch node for request routing
- Specialised context-loading workflows
- Separate agent workflows

## 5. Implementation Technology

- n8n Cloud
- OpenAI
- AI Agent
- Switch node
- Langfuse integration exploration

## 6. Current Status

Mira demonstrates a functional multi-agent
prototype with specialised workflows.

Further work is required to strengthen
orchestration, observability, governance
and production readiness.

## 7. Future Direction

Evolve Mira into a scalable, observable
and governed project intelligence solution.
